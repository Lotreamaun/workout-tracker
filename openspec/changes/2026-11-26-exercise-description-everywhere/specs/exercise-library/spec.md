## ADDED Requirements

### Requirement: Описание упражнения в библиотеке
`GET /api/exercises` и `GET /api/exercises/:id` SHALL возвращать поле `description` (строка или null). Для нормализованного названия библиотека MUST сохранить первое непустое описание при сохранении или импорте шаблона. При запуске API пустое поле MUST заполняться из самого раннего созданного шаблона с непустым описанием; при совпадении даты используется стабильный порядок по ID шаблона, затем по позиции упражнения. Сохранённое описание MUST оставаться прежним при последующих изменениях шаблонов.

#### Scenario: Первое непустое описание
- **WHEN** сохраняется упражнение «Жим лёжа» без описания, а затем два шаблона с непустыми описаниями для «жим лежа»
- **THEN** библиотека содержит одну запись с первым непустым описанием

#### Scenario: Заполнение существующей библиотеки
- **WHEN** API запускается с существующей библиотекой без описания и несколькими шаблонами с разными описаниями упражнения
- **THEN** берётся непустое описание из самого раннего созданного шаблона

### Requirement: Показ описания в библиотеке
Интерфейс SHALL показывать заданное описание под названием в списке упражнений и в карточке упражнения.

#### Scenario: Просмотр описания в библиотеке
- **WHEN** пользователь открывает упражнение с описанием
- **THEN** описание доступно и в списке, и в карточке упражнения
