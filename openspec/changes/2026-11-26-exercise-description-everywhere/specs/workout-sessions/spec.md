## ADDED Requirements

### Requirement: Снимок описания упражнения
При запуске сессии сервер SHALL скопировать описание упражнения из шаблона в снимок. Полная сессия SHALL возвращать `exercises[].description` со значением null, если описание в снимке отсутствует.

#### Scenario: Правка шаблона после запуска
- **WHEN** шаблон с упражнением с описанием запущен в сессию, а затем описание в шаблоне изменено
- **THEN** детали сессии содержат исходное описание упражнения

### Requirement: Доступ к описанию во время тренировки
В карточке упражнения с описанием интерфейс SHALL показывать действие «Описание упражнения» под названием. Описание раскрывается по нажатию; поля подходов доступны при свёрнутом описании.

#### Scenario: Просмотр длинного описания
- **WHEN** пользователь открывает тренировку с длинным описанием упражнения
- **THEN** описание свёрнуто, поля подходов доступны, а пользователь может раскрыть текст по нажатию
