## MODIFIED Requirements

### Requirement: Навигация по основным экранам
Интерфейс SHALL предоставлять навигацию между экранами «Главная», «Тренировки», «История», «AI-обмен» (нижняя панель на мобильных, боковая или верхняя на десктопе), использовать тёмную тему по умолчанию и русский язык интерфейса. Экран активной тренировки доступен по отдельному маршруту. Навигация на десктопе MUST оставаться видимой на месте при прокрутке содержимого экрана.

#### Scenario: Переход между экранами
- **WHEN** пользователь нажимает пункт навигации
- **THEN** открывается соответствующий экран без перезагрузки страницы

#### Scenario: Прокрутка длинного экрана на десктопе
- **WHEN** на десктопе пользователь прокручивает длинную тренировку вниз
- **THEN** боковая навигация остаётся видимой на прежнем месте, прокручивается только содержимое
