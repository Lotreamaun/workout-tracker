## Context

Только фронтенд (`apps/web`), API и данные не меняются. Текущее состояние:

- `AppLayout`: `aside` — обычный flex-элемент внутри `min-h-dvh`, поэтому прокручивается вместе со страницей.
- `WorkoutDetailPage` сразу рендерит `WorkoutEditor`. Архивная тренировка показывается как заблокированный `fieldset` с `opacity-50`.
- `Textarea` имеет фиксированную `min-h-20` и прокручивается внутри.
- Названия, описание упражнения и заметка подхода — однострочные `Input`.

## Goals / Non-Goals

**Goals:**
- Закреплённая навигация на десктопе.
- Полное отображение пользовательского текста в формах и на экранах.
- Отдельный экран просмотра шаблона.

**Non-Goals:**
- Описание и заметки шаблона на экране активной тренировки. Для этого нужен snapshot этих полей в сессии, то есть изменение схемы БД и API. Это отдельное изменение.
- Редизайн, новые цвета и шрифты.
- Перетаскивание упражнений.
- Автосохранение редактора.

## Decisions

1. **Закреплённый sidebar.** У `aside` на `md+` ставим `sticky top-0 h-dvh overflow-y-auto` (`self-start`). Прокручивается документ, а не внутренний контейнер, поэтому iOS-поведение, safe area и fixed-панели на мобильном не меняются.
   - Альтернатива: app-shell, где внутри `main` свой скролл. Отклонена: она меняет прокрутку на мобильном и ломает уже отлаженный safe-area.

2. **Поле с автовысотой: один компонент `AutoTextarea`** в `components/ui/auto-textarea.tsx`, обёртка над `Textarea`.
   - Высота пересчитывается в `useLayoutEffect` при изменении `value` и ширины, через `ResizeObserver`: `height = auto`, затем `scrollHeight`.
   - Внутреннего скролла нет (`overflow-hidden`, `resize-none`).
   - Минимальная высота задаётся через `rows`.
   - Пропс `singleLine`: Enter не вставляет перевод строки, а переводы строк из вставленного текста заменяются пробелами. Это нужно для названий.
   - CSS `field-sizing: content` не используем. Поддержка в Safari на iOS не гарантирована, а JS-вариант работает везде и даёт одинаковое поведение.

3. **Где применяем `AutoTextarea`:**

   | Поле | Режим |
   |---|---|
   | название тренировки | `singleLine` |
   | описание тренировки | многострочный |
   | название упражнения | `singleLine` |
   | описание упражнения | многострочный, раньше было `Input` |
   | заметки упражнения | многострочный |
   | заметка подхода в активной сессии | многострочный, `rows=1` |
   | заметки к тренировке в сессии | многострочный |

   Поля для JSON в AI-обмене не трогаем: там большой фиксированный блок уместнее.

4. **Просмотр и редактирование — разные маршруты.**
   - `/workouts/:id` → новый `WorkoutView`. Показывает:
     - название, описание;
     - карточки упражнений: номер, название, строка плана «3 × 8 × 60 кг · отдых 90 с», описание, заметки с `whitespace-pre-wrap`.
   - Кнопки: «Начать» (основная) и «Редактировать» (outline) ведут на `/workouts/:id/edit`, там `WorkoutEditor`.
   - После сохранения: редактирование → `/workouts/:id`; создание → `/workouts/:newId`, где id берётся из ответа `createWorkout`.
   - Кнопка удаления остаётся в редакторе.
   - Архивная тренировка: только просмотр с пометкой, без «Начать» и «Редактировать». Прямой заход на `/edit` архивной тренировки перенаправляет на просмотр.
   - Альтернатива: переключатель режима в одном маршруте. Отклонена: кнопка «Назад» браузера и iOS-свайп назад ведут себя неочевидно, а сохранение всё равно требует навигации.

5. **Перенос текста.** Для пользовательского текста — названий в `h1`, карточках и списках, описаний, заметок — используем `break-words` (`overflow-wrap: anywhere` через утилиту Tailwind `wrap-anywhere`) и `min-w-0` у flex-родителей. Для многострочных заметок — `whitespace-pre-wrap`.

## Risks / Trade-offs

- [Пересчёт высоты `textarea` дёргает layout на каждый ввод] → Полей немного (до 50 упражнений по 3 поля), пересчёт дешёвый. Достаточно `useLayoutEffect` по `value`.
- [Заметка подхода в виде `textarea` и iOS-клавиатура: Enter даёт перевод строки, а не «Готово»] → Для заметки это ожидаемо. Сохранение и так идёт по blur и debounce.
- [Старые ссылки и закладки на `/workouts/:id`] → Маршрут сохраняется, только теперь он показывает просмотр.
