## Context

Таблицы `workout_sessions` и `set_logs` (со snapshot-полями `exercise_name_snapshot`, `exercise_position`, `planned_*`, `rest_seconds`, `is_skipped`) созданы в `foundation`; шаблоны — в `workout-builder`.

## Goals / Non-Goals

**Goals:** надёжная запись факта с минимумом действий, точный таймер, неизменная история.

**Non-Goals:** добавление/удаление подходов во время сессии, замена упражнения, суперсеты, графики, серверное хранение таймера, push-уведомления.

## Decisions

### Модель упражнения в сессии
Отдельной таблицы «упражнения сессии» нет: упражнение сессии = группа `set_logs` по `exercise_position`; имя/отдых берутся из snapshot первого подхода; `isSkipped` упражнения хранится на всех его подходах и выставляется сразу для всей группы. Альтернатива (новая таблица `session_exercises`) чище, но требует миграции и усложняет импорт; для MVP группировки достаточно.

### Одна активная сессия
Запуск при наличии `in_progress` → 409 с `sessionId`. Это упрощает Главную («Продолжить») и исключает «забытые» сессии. Выход — завершить или отменить (`status: "abandoned"`).

### Модуль API
`modules/sessions/{routes.ts, service.ts, repository.ts}`; маршрут `POST /api/workouts/:id/sessions` регистрируется в модуле sessions (он владеет логикой snapshot). Запуск и PATCH — в транзакции. Время — `new Date().toISOString()` на сервере.

### Клиент: автосохранение
Отметка подхода и пропуск — немедленный PATCH. Текстовые/числовые поля — локальное состояние, PATCH по blur или с debounce ~600 мс. Оптимистичное обновление кэша react-query с откатом при ошибке и toast/сообщением.

### Таймер
Чистая функция `getRemainingMs(endsAt, now)` и хук `useRestTimer(sessionId)`: состояние `{ endsAt, durationMs }` в `localStorage` (`wt:rest:<sessionId>`) с try/catch; тик через `setInterval(250)` только для перерисовки; при `visibilitychange` — немедленный пересчёт. По окончании — `navigator.vibrate?.(…)`, визуальный акцент. Компонент `RestTimer` — фиксированная панель внизу экрана над навигацией.

### Отображение
Плановое — приглушённым текстом/placeholder («8 × 80 кг»), фактическое — в полях ввода. Даты — `Intl.DateTimeFormat('ru-RU')` в локальной зоне.

## Risks / Trade-offs

- [iOS PWA усыпляет JS в фоне] → таймер по timestamp; вибрация/звук в фоне не обещаются.
- [Потеря ввода при обрыве сети] → показывать ошибку сохранения; оффлайн-очередь вне MVP.
- [Группировка по `exercise_position`] → позиция фиксируется при запуске и не меняется в сессии.
