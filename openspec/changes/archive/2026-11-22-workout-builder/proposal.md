## Why

Базовый сценарий MVP начинается с плана: пользователь должен создать шаблон тренировки с упражнениями и плановыми параметрами, прежде чем выполнять его (блок 2 README).

## What Changes

- REST API шаблонов: `GET/POST /api/workouts`, `GET/PATCH/DELETE /api/workouts/:id`.
- Упражнения вложены в шаблон и управляются через payload тренировки (упорядоченный массив) — без отдельных endpoints и без глобальной библиотеки.
- Удаление: шаблон без истории удаляется физически, шаблон с историей сессий архивируется (скрывается из списка, история остаётся).
- Общие Zod-схемы ввода/вывода тренировок в `packages/shared`.
- UI: список тренировок, создание/редактирование (название, описание, упражнения с подходами/повторами/весом/отдыхом/заметками), изменение порядка кнопками вверх/вниз, удаление с подтверждением.

## Capabilities

### New Capabilities
- `workout-builder`: создание, чтение, изменение, удаление/архивирование шаблонов тренировок и вложенных упражнений с плановыми параметрами и порядком.

## Impact

- `apps/api/src/modules/workouts/` (routes, service, repository), регистрация в `app.ts`.
- `packages/shared/src/workouts.ts`.
- `apps/web`: экраны `/workouts`, `/workouts/new`, `/workouts/:id`, хуки react-query.
