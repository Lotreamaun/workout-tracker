## MODIFIED Requirements

### Requirement: Конфигурация через окружение
API base URL клиента, порт и host backend, путь к БД, каталог медиа (`MEDIA_DIR`), путь к ffmpeg, ключ доступа (`API_TOKEN`) и разрешённые CORS-origin SHALL задаваться переменными окружения. В репозитории MUST быть `.env.example`, а `.env`, файлы БД, каталог медиа и `uploads/` MUST быть в `.gitignore`.

#### Scenario: Запрос с неразрешённого origin
- **WHEN** браузер с origin, отсутствующим в списке разрешённых, делает запрос к API
- **THEN** ответ не содержит заголовков, разрешающих этот origin

#### Scenario: Каталог медиа по умолчанию
- **WHEN** `MEDIA_DIR` не задан
- **THEN** медиа хранятся в `data/media` (на том же volume, что и БД)

### Requirement: Навигация по основным экранам
Интерфейс SHALL предоставлять навигацию между экранами «Главная», «Тренировки», «Упражнения», «История», «AI-обмен» (нижняя панель на мобильных, боковая или верхняя на десктопе), использовать тёмную тему по умолчанию и русский язык интерфейса. Экран активной тренировки доступен по отдельному маршруту. Навигация на десктопе MUST оставаться видимой на месте при прокрутке содержимого экрана.

#### Scenario: Переход между экранами
- **WHEN** пользователь нажимает пункт навигации
- **THEN** открывается соответствующий экран без перезагрузки страницы

#### Scenario: Прокрутка длинного экрана на десктопе
- **WHEN** на десктопе пользователь прокручивает длинную тренировку вниз
- **THEN** боковая навигация остаётся видимой на прежнем месте, прокручивается только содержимое
