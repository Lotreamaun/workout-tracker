## Why

Когда экран iPhone заблокирован или трекер свёрнут, таймер страницы может приостановиться. Системный Web Push позволит узнать об окончании отдыха в это время.

## What Changes

- Добавить уведомление «Отдых окончен» для PWA, установленного на домашний экран iPhone с iOS 16.4 и новее.
- Запрашивать разрешение по кнопке пользователя и дать возможность отключить уведомления на устройстве.
- Планировать отправку на сервере при старте отдыха и обновлять или отменять её вместе с таймером.
- По нажатию на уведомление открывать соответствующую тренировку.

## Capabilities

### New Capabilities

- `pwa-rest-web-push` — системные уведомления об окончании отдыха для iPhone.

### Modified Capabilities

Нет.

## Impact

Общий таймер отдыха, service worker PWA, Fastify API, миграции SQLite и параметры развёртывания.
